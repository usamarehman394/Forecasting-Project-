# Forecasting-Project-
The title for our group Project is "Demand Forecasting and Optimization".
For this project we selected a dataset from Kaggle named as Food Demand Forcasting.
The link to this dataset is "https://www.kaggle.com/datasets/kannanaikkal/food-demand-forecasting?utm_source=chatgpt.com"
Our dataset will help us to assess historical demand for various meal-center combinations so that the food delivery service can predict future orders. This helps in inventory management, reducing food wastage, and optimizing logistics.
